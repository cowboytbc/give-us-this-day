# GIVE US THIS DAY

A responsive, single-page deathcore band website built with Vite, HTML, CSS, and JavaScript.

## Local development

Install dependencies, then start the development server:

- `npm install`
- `npm run dev`

Create a production build with `npm run build`.

## Replace before publishing

- Update the show dates and ticket destinations in `index.html`.
- Replace the placeholder streaming and social destinations.
- Change `contact@giveusthisday.com` to the band's active contact inbox.
